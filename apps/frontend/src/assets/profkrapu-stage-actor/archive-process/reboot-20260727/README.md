# ProfKrapu Stage Actor Reboot — Direction Draft

Ce dossier contient les premiers essais Stage Actor generes depuis le canon ProfKrapu V4.

## Statut

- `raw/`, `alpha/`, `normalized/` : preuves de generation et de cadrage.
- Les images `neutral-*` et `listening-*` ne sont pas un pack valide.
- Probleme identifie : le couple `left/right` ne lit pas assez comme un vrai champ/contrechamp UI.

## Contrat A Refaire

- `left` : personnage place sur le bord gauche, regard/torse franchement orientes vers le centre/droite.
- `right` : personnage place sur le bord droit, regard/torse franchement orientes vers le centre/gauche.
- `right` ne doit pas etre un miroir mecanique.
- Le couple doit marcher comme deux interlocuteurs autour du centre de l'interface.

## Prochaine Action

Regenerer `neutral-left` depuis `profkrapu-canon-v4.png` avec le contrat directionnel strict.
Ne produire `neutral-right` qu'apres validation du `left`.
