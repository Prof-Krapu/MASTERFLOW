# Auditer la cohérence

1. Identifier les deux couches comparées et leur source de vérité.
2. Collecter une preuve minimale dans chaque couche.
3. Produire : élément, statut, écart, risque, action recommandée.
4. Classer le finding : information, dette, blocage, dérive produit ou preuve manquante.
5. Ne pas corriger automatiquement un écart sensible.
6. Ajouter les vrais écarts à la queue; ignorer le bruit déjà attribué.
7. Refaire le contrôle après patch et avant publication.
