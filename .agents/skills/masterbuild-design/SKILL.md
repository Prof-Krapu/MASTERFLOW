# Design Preflight MASTERBUILD

1. Lire `MASTERBUILD.md` et le Round actif.
2. Identifier surface, audience, contributeur et feature liée.
3. Lancer `npm run masterbuild:preflight -- <surface> <audience> <malex|vincent>`.
4. Présenter décisions verrouillées, zones libres, états obligatoires et données backend.
5. Vérifier les composants existants dans le Lab avant toute création.
6. Implémenter uniquement après GO du Round.
7. Faire relire expérience/DA par MALEX et contrats/permissions par Vincent avant promotion.

MUI est une source de principes. Ne pas ajouter Material UI sans décision explicite.
