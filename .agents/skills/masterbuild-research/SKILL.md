# Cadrer une recherche

1. Chercher d’abord dans le canon, Git, les Factories et les archives pertinentes.
2. Si la preuve manque ou peut avoir changé, proposer la recherche.
3. Afficher : pourquoi, question exacte, coût léger/moyen/important, sortie attendue.
4. Privilégier documentation officielle, standards et sources primaires.
5. Classer le résultat `candidate_evidence`.
6. Distinguer faits, inférences et recommandation.
7. Ne rien intégrer au canon sans décision humaine.
